# 安全边界说明

## 项目安全限制

本项目严格遵守以下安全边界：

### 文件系统
- 所有文件仅在 `offline-workbench/` 目录内创建、修改、删除
- 禁止修改项目目录外的任何文件
- 禁止删除项目目录外的任何文件

### 系统安全
- 禁止修改系统设置
- 禁止修改注册表
- 禁止安装系统服务
- 禁止创建开机自启动项
- 禁止修改 PATH、全局环境变量、Shell 配置文件
- 禁止使用管理员权限
- 禁止执行危险命令（rm -rf、del /s、format、diskpart、shutdown、taskkill 等）

### 网络安全
- 禁止联网调用第三方 API
- 禁止接入云服务
- 禁止使用远程数据库
- 禁止把任何数据发送到外部网络
- 不使用 CDN

### 隐私安全
- 禁止扫描用户私人目录（Desktop、Documents、Downloads、Pictures、Videos、OneDrive 等）
- 禁止读取、上传、复制、索引项目目录外的个人文件
- 禁止访问微信、QQ、浏览器配置、SSH、Git 凭据

### 数据安全
- 所有数据仅保存在浏览器 localStorage 中
- 不自动读取任何本地文件
- 导入功能仅允许用户手动选择文件
- 删除和清空操作必须二次确认

### 依赖安全
- 不引入不必要的大型依赖
- 优先使用纯 HTML、CSS、JavaScript 实现
- 不使用 npm、不使用后端、不使用构建工具
