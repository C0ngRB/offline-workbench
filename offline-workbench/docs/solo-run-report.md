- 项目名称：Offline Workbench

## 开发过程

### 阶段一：项目规划

根据操作方案，明确了项目目标、技术约束、功能需求和安全限制。将项目拆分为以下模块：

1. `storage.js` - 数据存储层
2. `timer.js` - 番茄钟逻辑
3. `tasks.js` - 任务管理
4. `notes.js` - 笔记管理
5. `templates.js` - 检查清单模板
6. `exportImport.js` - 导入导出
7. `app.js` - 主应用入口、路由、仪表盘、设置、搜索、统计
8. `main.css` - 样式
9. `index.html` - 页面结构

### 阶段二：模块实现

按照依赖顺序依次实现各模块：

1. 先实现 `storage.js`，提供统一的数据读写接口
2. 实现各功能模块，每个模块使用 IIFE 模式封装
3. 实现 `app.js`，整合所有模块并提供路由
4. 实现 CSS 样式，包含绿色主题、深色模式和响应式
5. 实现 HTML 页面结构

### 阶段三：增强功能

核心功能完成后，继续实现低风险增强：

1. 搜索功能 - 搜索任务、笔记、模板
2. 统计页面 - 数据概览和分类统计图
3. 示例数据按钮 - 设置页面提供加载示例数据
4. 打印友好样式 - @media print 隐藏导航和按钮

## 遇到的问题及解决方式

### 问题 1：Windows PowerShell mkdir 不支持 -p 参数

- **现象**：`mkdir -p` 在 PowerShell 中报错
- **解决**：改用 `New-Item -ItemType Directory -Force -Path` 命令

### 问题 2：Markdown 解析需要无依赖实现

- **现象**：不能使用第三方 Markdown 库
- **解决**：使用正则表达式实现简单 Markdown 解析，支持标题、粗体、斜体、列表、代码、代码块

### 问题 3：番茄钟刷新后状态保持

- **现象**：用户刷新页面后计时器状态丢失
- **解决**：在 localStorage 中保存计时器状态（包括 startedAt 时间戳），页面加载时计算已过去的时间并恢复

### 问题 4：深色模式实现

- **现象**：需要支持浅色/深色切换
- **解决**：使用 CSS 自定义属性（CSS Variables）和 `data-theme` 属性，在 `:root` 和 `[data-theme="dark"]` 中定义不同颜色值
