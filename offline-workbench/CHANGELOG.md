# 更新日志

## v1.0.0 - 2026-05-06

### 新增功能

- 首页仪表盘：今日任务数、完成数、专注次数、笔记数量、进度条、最近笔记
- 任务清单：新增、编辑、删除、标记完成、优先级（高/中/低）、分类（学习/开发/论文/实验/杂项）、筛选
- 番茄钟：25 分钟专注 / 5 分钟短休息 / 15 分钟长休息、开始/暂停/重置、专注次数记录、环形进度条
- Markdown 笔记：新增、编辑、删除、简单 Markdown 预览（标题、列表、代码块、粗体、斜体）
- 检查清单模板：6 个内置模板（代码提交前检查、论文修改检查、实验运行前检查、GIS 数据处理检查、Trae/Codex 交付检查、下班前检查）
- 数据导入导出：导出 JSON 文件、从 JSON 文件导入、格式校验、错误提示
- 设置：浅色/深色模式切换、番茄钟时长自定义、重置默认设置、清空全部数据（二次确认）、加载示例数据
- 搜索功能：搜索任务、笔记、模板
- 统计页面：今日完成数、总专注次数、笔记数量、各分类任务数量、任务状态分布
- 打印友好样式：隐藏导航和按钮，适合打印任务清单和检查清单
- 响应式设计：适配 1366px 桌面屏和手机窄屏
