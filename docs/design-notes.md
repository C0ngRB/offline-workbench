# 设计笔记

## 架构设计

采用纯前端单页应用（SPA）架构，使用 IIFE 模式封装各模块，通过全局变量暴露接口。

### 模块划分

| 模块 | 职责 |
|------|------|
| Storage | 统一管理 localStorage 读写 |
| Timer | 番茄钟计时逻辑和 UI |
| Tasks | 任务 CRUD 和列表渲染 |
| Notes | 笔记 CRUD 和 Markdown 预览 |
| Templates | 检查清单模板和清单管理 |
| ExportImport | JSON 导入导出 |
| App | 路由、仪表盘、设置、搜索、统计 |

### 数据流

1. 用户操作触发模块方法
2. 模块调用 Storage 进行数据持久化
3. 模块重新渲染对应页面区域

### 路由机制

使用简单的页面切换方式：通过 `data-page` 属性绑定导航事件，点击时隐藏所有页面、显示目标页面，并调用对应模块的渲染函数。

## UI 设计

- 主色调：绿色 (#2ecc71)
- 圆角卡片风格
- 左侧固定导航栏
- 响应式布局：桌面端侧边栏固定，移动端汉堡菜单
- 深色模式通过 CSS 自定义属性实现

## Markdown 解析

使用正则表达式实现简单 Markdown 解析，支持：
- 标题（#、##、###）
- 粗体（**text**）
- 斜体（*text*）
- 无序列表（- item）
- 行内代码（`code`）
- 代码块（```code```）

解析顺序：先处理代码块（避免内部被其他规则影响），再处理行内代码，然后标题、粗体、斜体、列表，最后处理段落和换行。
